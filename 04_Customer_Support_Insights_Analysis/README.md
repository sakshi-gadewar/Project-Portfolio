### Customer Support Insights Analysis

This project is about analyzing customer support ticket data using Microsoft Power BI. I created an interactive dashboard to understand ticket status, priority levels, support channels, issue categories, and regional performance.

The main goal of this project is to make it easier to track customer support activities, identify common issues, and understand where the support team may need improvement.

### Project Overview
- Track total tickets and resolved tickets.
- Understand how tickets are distributed across different priority levels.
- Analyze ticket volume by month and support channel.
- Compare ticket status across Open, In Progress, and Closed categories.
- Identify the most common customer support issues.
- Compare ticket volume across different regions.
- Monitor SLA compliance and average wait time.

  ---

  ### Business Problem
  A support team needs to know:
- How many tickets are coming in, and how many are resolved?
- Which issue categories and channels create the most workload?
- Which regions and months need more attention?

This dashboard answers these questions in one view so a support manager can plan staffing and fix the biggest problems first.

---

### Tools & Skills Used
- Power BI Desktop – dashboard design and interactive visuals
- DAX – measures for resolved tickets, average wait time, and SLA %
- Power Query – data cleaning and preparation
- Data Validation – checking totals and status counts against the source data

  ---

### Dashboard Features

1. KPI Cards
The dashboard includes key metrics such as:
- Total Tickets
- Resolved Tickets
- Average Wait Time
- SLA Compliance

 2. Ticket Priority Analysis
Shows the number of tickets classified as High, Medium, and Low priority. This helps compare the support workload across priority levels.

3. Monthly Ticket Trends
Displays ticket volume by month to help identify changes in support demand over time.

4. Channel Analysis
Compares tickets received through Email, Chat, and Phone to understand how customers use different support channels.

5. Ticket Status Analysis
Shows the distribution of Open, In Progress, and Closed tickets to help monitor the current ticket backlog.

6. Regional Analysis
Compares ticket volume across the South, North, East, and West regions.

7. Category Analysis
Highlights common customer issues, including Login Issues, Payment Issues, App Bugs, Account Issues, and Delivery Issues.

8. Date Filter
Allows users to select a date range and explore ticket performance for the selected period.

---

### Key Insights

- Medium-priority tickets account for the largest share of the support workload.
- Login and Payment issues are the two most common ticket categories.
- Email is the most frequently used support channel.
- The South region has the highest ticket volume among the four regions.
- Open and in-progress tickets highlight the need to monitor unresolved requests.
